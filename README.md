## CodeCompass integration

CodeCompass is presented as a decisive Ananta subproject on the website. The page explains how CodeCompass acts as Ananta's knowledge graph, retrieval and policy-aware context-control layer.

The website links CodeCompass from:

- the main navigation
- the hero action buttons
- the feature cards
- the project status strip
